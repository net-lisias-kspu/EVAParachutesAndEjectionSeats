# EVA Parachutes & Ejection Seats /L Unleashed :: Archive

Provides parachutes for all Kerbals on EVA, as well ejection modules, to be able to eject all Kerbals from a craft in an Abort sequence.

[Unleashed](https://ksp.lisias.net/add-ons-unleashed/) fork by Lisias.
